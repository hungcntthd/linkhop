Quản lý đường link cuộc họp

Dán đường dẫn, bật phòng và nhấn Lưu thay đổi. Người dùng trên Smart TV sẽ nhìn thấy link mới trong khoảng 30 giây (khi kết nối mạng ổn định).

Cần kết nối Firebase

Website chưa có cấu hình Firebase hợp lệ. Quản trị viên IT hãy điền firebase-config.js, thiết lập Authentication và Realtime Database Rules theo file HUONG_DAN_CAI_DAT.md, sau đó tải các file lên GitHub.

Đăng nhập quản trị

Tài khoản được tạo trong Firebase Authentication bởi người quản lý hệ thống. Không dùng mật khẩu GitHub tại đây.

Danh sách phòng họp

Nếu sửa nhiều phòng, nhấn Lưu thay đổi một lần. Bấm Tải lại dữ liệu sẽ hủy những chỉnh sửa chưa lưu trên trang này.

Lưu ý bảo mật: Danh sách đường dẫn hiển thị công khai để Smart TV mở không cần đăng nhập. Không nhập mật khẩu, token hoặc link cuộc họp bí mật vào hệ thống này. Việc đăng nhập quản trị chỉ giới hạn quyền chỉnh sửa, không giới hạn quyền xem link.
